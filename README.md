# 民數記 14:22 十次試探互動式地圖

這是一個單頁靜態網頁，用互動式地圖呈現民數記 14:22 所說「試探我這十次」的常見整理。頁面標示十次事件的近似位置、事件摘要與經文依據，並提供清單點選、地圖彈窗、路線顯示與依序播放功能。

## 專案內容

- `index.html`：完整互動式地圖頁面，包含 HTML、CSS 與 JavaScript。
- 使用 [Leaflet](https://leafletjs.com/) 顯示地圖。
- 使用 [OpenStreetMap](https://www.openstreetmap.org/) 作為底圖。

## 十次事件

1. 紅海前懼怕抱怨，出埃及記 14:10-12
2. 瑪拉苦水，出埃及記 15:22-24
3. 汛的曠野求食，出埃及記 16:1-3
4. 留下嗎哪到早晨，出埃及記 16:19-20
5. 安息日出去收嗎哪，出埃及記 16:27-30
6. 利非訂無水，出埃及記 17:1-7
7. 金牛犢，出埃及記 32:1-10
8. 他備拉發怨言，民數記 11:1-3
9. 基博羅哈他瓦貪慾，民數記 11:4-35
10. 加低斯巴尼亞探子事件，民數記 13:25-14:23

## 使用方式

直接用瀏覽器開啟 `index.html`。

也可以用本機靜態伺服器執行：

```bash
python3 -m http.server 4173
```

然後開啟：

```text
http://127.0.0.1:4173/
```

## 地點說明

出埃及路線與部分曠野站點在考古與釋經上沒有一致定位。本專案採教學用途的近似座標與傳統候選位置，適合用來呈現事件順序與大致路線，不應視為唯一地理結論。

## 部署

此專案是純靜態網頁，可部署到 GitHub Pages。建議設定：

- Source: `Deploy from a branch`

- Folder: `/ (root)`
